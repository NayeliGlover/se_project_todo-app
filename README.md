# Daily Dos

A clean, responsive web application for managing daily tasks, built with modular JavaScript and instant form validation.

## Functionality

- Task Management: Users can add new to-do items with a title and optional due date, mark tasks as complete, and delete items from the list.
- Instant Form Validation: Input fields are checked as the user types, displaying clear error messages and keeping the submit button disabled until all fields are valid.
- Modal Controls: Pop-up forms can be closed using the close button, clicking outside the modal, or pressing the Escape key.

## Technology

- HTML5: Semantic structure and `<template>` elements for rendering task items.
- CSS3: Responsive layout and styling using Flexbox and BEM naming conventions.
- JavaScript (ES6+): Object-Oriented Programming (OOP) using ES6 classes (Todo, FormValidator) and ES6 modules (import / export).
